# TRM Domain

| Title | Technology Domain Code | Technology Domain Name | Technology Domain Description | Technology Domain Comments |
| --- | --- | --- | --- | --- |
| TD001 End-User Computing | TD001 | End-User Computing | The End-User Computing domain contains the technologies that provide tools, services, and capabilities for end-users to interact with systems and use foundation services. |  |
| TD008 Communication & Collaboration | TD008 | Communication & Collaboration | Communication & Collaboration technologies facilitate information exchange, interaction, and joint work between people. | Communication & Collaboration technologies cover a broad scope of technical capability, and include Unified Communication & Collaboration platforms. Such technologies enable people to interact and work together regardless of their physical location. |
| TD007 Digital Identity | TD007 | Digital Identity | Digital Identity technologies are foundational to the identification and authentication, authorisation and access, and lifecycle-management services applicable to individuals and entities. |  |
| TD003 Data & Information | TD003 | Data & Information | The Data & Information domain contains the technologies that provide services to store and manage structured and unstructured data. |  |
| TD002 Software Delivery & Execution | TD002 | Software Delivery & Execution | The Software Delivery & Execution domain contains the technologies used to create, deploy, and run digital solutions. |  |
| TD004 Infrastructure | TD004 | Infrastructure | The Infrastructure domain contains the technologies that provide compute, storage, networking, and higher-order platform services. |  |
| TD005 Cybersecurity | TD005 | Cybersecurity | The Cybersecurity domain contains the technology capabilities required to protect systems, networks, programs, and assets from digital attacks. |  |
| TD006 Technology Operation | TD006 | Technology Operation | The Technology Operation domain contains the technologies that provide administration and observation across all tiers of the technology stack. |  |
